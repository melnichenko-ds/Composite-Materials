# Composite-Materials
Выпускная квалификационная работа по курсу 'Наука о данных: профессиональный уровень (Data Science PRO'. Тема: 'Прогнозирование конечных свойств композиционных материалов'. 
Композиционные материалы обладают уникальными свойствами, которые не наблюдаются у компонентов по отдельности, однако прогнозирование их конечных характеристик на основе свойств исходных компонентов является нетривиальной задачей. Традиционный метод проб и ошибок требует значительных временных и материальных затрат.
Целью работы является прогнозирование механических свойств композиционных материалов (модуля упругости при растяжении и прочности при растяжении) методами машинного обучения, а также разработка нейронной сети для рекомендации оптимального соотношения матрица-наполнитель и веб-приложения для практического использования моделей.
Задачи: 
1) Провести разведочный анализ данных (EDA).
2) Выполнить предобработку данных (удаление выбросов, нормализация).
3) Обучить несколько моделей машинного обучения для прогнозирования модуля упругости и прочности при растяжении.
4) Разработать нейронную сеть для рекомендации соотношения матрица-наполнитель.
5) Создать веб-приложение для практического использования моделей.
6) Разместить код проекта в репозитории GitHub.
