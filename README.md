## Актуальность работы

Создание новых композиционных материалов требует значительных временных 
и финансовых затрат на проведение физических испытаний. Даже зная 
характеристики исходных компонентов, определить конечные свойства 
композита достаточно проблематично — традиционный метод проб и ошибок 
становится экономически неэффективным.

Применение методов машинного обучения позволяет **сократить количество 
проводимых испытаний**, ускорить разработку новых материалов и пополнить 
базу данных цифровыми двойниками композитов.

---

## Цель работы

Прогнозирование механических свойств композиционных материалов 
(модуля упругости при растяжении и прочности при растяжении) методами 
машинного обучения, а также разработка нейронной сети для рекомендации 
оптимального соотношения матрица-наполнитель и веб-приложения 
для практического использования моделей.

---

## Выполненные задачи

В ходе работы были решены следующие задачи:

1. **Проведён разведочный анализ данных (EDA).** 
   Построены гистограммы распределения, диаграммы ящика с усами, 
   попарные графики рассеяния и матрица корреляции. Проверена 
   нормальность распределений с помощью теста Шапиро–Уилка. 
   Выявлены выбросы и слабая связь признаков с целевыми переменными.

2. **Выполнена предобработка данных.** 
   Удалены выбросы по IQR-методу, проведена нормализация признаков 
   с помощью MinMaxScaler, данные разделены на обучающую (70%) 
   и тестовую (30%) выборки.

3. **Обучены пять моделей машинного обучения** для прогнозирования 
   модуля упругости и прочности при растяжении: линейная регрессия, 
   случайный лес, XGBoost, SVR и KNN. Для каждой модели выполнен 
   поиск гиперпараметров с помощью GridSearchCV с 10-кратной 
   кросс-валидацией. Проведена оценка качества по метрикам MAE, RMSE и R².

4. **Разработана нейронная сеть** (полносвязная, MLP) для рекомендации 
   соотношения матрица-наполнитель. Архитектура: 12 → 64 → 32 → 1, 
   Dropout 0.2, обучение 200 эпох с оптимизатором Adam.

5. **Создано веб-приложение** на основе FastAPI с веб-интерфейсом 
   для ввода 12 параметров композита и получения прогноза 
   соотношения матрица-наполнитель.

6. **Код проекта размещён в репозитории на GitHub** с полной 
   документацией и инструкцией по запуску.

## Достигнутые результаты

- **Проведён полный цикл анализа данных** — от разведочного анализа 
  и предобработки до обучения моделей, разработки нейросети 
  и деплоя приложения.

- **Выявлены ограничения исходных данных:** матрица корреляции 
  показала, что связь между признаками и целевыми переменными 
  близка к нулю (коэффициенты не превышают 0.11).

- **Все модели для прогнозирования свойств** показали R² близкий 
  к нулю или отрицательный — они не превзошли базовую модель, 
  предсказывающую среднее значение.

- **Нейронная сеть для рекомендации соотношения** показала 
  R² = −0.01 и не превзошла baseline.

- **Создано работающее веб-приложение**, корректно обрабатывающее 
  входные данные и возвращающее прогноз модели.

- **Сформирована основа для дальнейших исследований:** код, 
  обученные модели, веб-приложение и документация.

## Ценность работы

Работа представляет **методическую и практическую ценность**:

1. **Продемонстрирован полный цикл Data Science** — от разведочного 
   анализа и предобработки данных до обучения моделей машинного 
   обучения, разработки нейронной сети, создания веб-приложения 
   и размещения кода в репозитории.

2. **Выявлены ограничения исходного датасета** для решения 
   поставленных задач. Показано, что стандартные методы машинного 
   обучения не дают результата при слабой связи признаков 
   с целевыми переменными.

3. **Создана основа для дальнейших исследований:** работающее 
   приложение, репозиторий с кодом и документацией могут быть 
   использованы как стартовая точка для расширения набора данных 
   или применения физически обоснованных моделей.

4. **Определено направление развития:** для повышения качества 
   прогнозов рекомендуется расширение набора входных данных 
   (микроструктура, химический состав компонентов) или применение 
   моделей, учитывающих механику композиционных материалов.
